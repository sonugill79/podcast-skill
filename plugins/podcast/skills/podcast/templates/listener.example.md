# Listener profile (optional)

Copy this somewhere private, fill it in, and point the plugin at it:

    /plugin configure podcast     # set "listener_profile" to the file's path

With a profile, the hosts address you by name and connect the topic to your work. Without one, episodes are written
for a general audience — everything else works the same.

Keep it short. It is context, not a CV.

- **Name:** what the hosts should call you, spelled the way it should be *said*.
- **Where:** city or region, so local specifics can be researched.
- **Work:** current role and field, plus anything earlier that still shapes how you think.
- **Projects:** what you are building or responsible for, so a topic can be tied to it.
- **Interests and constraints:** what you care about, what you would never buy, how you like decisions framed.
- **Preferences:** e.g. "quote figures and sources", "skip the hype", "tell me what is unverified".

Anything you put here is read only on your machine, and only to write the script.
